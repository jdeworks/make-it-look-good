Button System

E-commerce component library · 3 emphasis levels × 4 states × 3 sizes

Primary color: emerald-600 (#059669) · Min touch target: 44px · WCAG AA compliant

1. Primary Buttons

Filled green · High emphasis · One per visual section maximum

Small (36px visible / 44px touch target)

Medium (44px — default)

Large (52px — hero CTAs, checkout)

State labels: Default Hover Focus Disabled Loading

When to use: The primary button is for the single most important action on the screen — "Add to Cart," "Place Order," "Sign Up." Limit to one primary button per visual section. If you need two actions, pair a primary with a secondary.

2. Secondary Buttons

Outlined · Medium emphasis · Supporting actions

Small

Medium

Large

When to use: Secondary buttons pair with primary buttons as the less-important option. "Continue Shopping" next to "Checkout," or "Save for Later" next to "Add to Cart." They can also stand alone for medium-priority actions like "View Details" or "Compare."

3. Ghost / Tertiary Buttons

Text only · Low emphasis · Escape hatches and minor actions

Small

Medium

Large

When to use: Ghost buttons are for the least important actions — "Cancel," "Skip," "Go Back," "Learn More." They intentionally look like links to reduce visual weight. Use them when you want an action available but not competing with the primary CTA.

4. Danger Buttons

Red filled · Destructive actions only · Always pair with confirmation

Outlined Danger (lower emphasis)

When to use: Danger buttons are exclusively for destructive, irreversible actions: "Delete Account," "Remove Item," "Cancel Order." Always include a trash/warning icon — do not rely on color alone (red/green color blindness affects ~8% of men). Pair with a confirmation dialog for high-stakes actions.

5. Icon Buttons

Icon-only and icon+text combinations

Icon Only (must have aria-label)

Icon + Text

When to use: Icon-only buttons are for well-understood actions (cart, heart, close, search, delete). Always set aria-label — icons have no text for screen readers. When the action is ambiguous, use icon+text. Place the icon before the label (left side in LTR layouts).

6. Button Group

Related actions grouped together · Primary always rightmost (in LTR)

Product Page Actions

Checkout Actions

Destructive Confirmation Dialog

Delete this item?

This action cannot be undone. The item will be permanently removed from your cart.

When to use: Group related actions together. Place the primary (most important) action on the right in LTR layouts — users scan left to right, so the last button gets the most attention. Use escalating emphasis: ghost → secondary → primary. In destructive dialogs, always make "Cancel" the ghost/secondary button and "Delete" the danger button.

Full Width (mobile pattern)

Sizing rules: Use Medium (44px) as the default for most buttons. Use Large (52px) for primary CTAs in hero sections, checkout flows, and anywhere the button is the main purpose of the screen. Use Small (36px) only in tight spaces like table rows or inline actions — but ensure the touch target still reaches 44px on mobile. Full-width buttons work well on mobile for primary actions at the bottom of a screen.

# Type Scale

> **TL;DR:** Use a modular scale with a ratio between 1.200 (minor third) and 1.333 (perfect fourth) for most projects. Base size: 16px minimum. This gives you a harmonious set of font sizes from body text through headings. Use `rem` units, not `px`.

## Core Principles

1. **A type scale is a set of font sizes generated by multiplying a base size by a consistent ratio**
2. **The ratio determines the visual contrast between levels** — smaller ratios (1.125) for dense UIs, larger ratios (1.5) for editorial/marketing
3. **Base size is 16px (1rem)** — this is the browser default and the accessibility minimum for body text
4. **Use `rem` for font sizes** — respects user browser settings; `px` overrides user preferences
5. **Limit to 5–7 distinct sizes** — more creates visual noise, fewer creates insufficient hierarchy

## Concrete Rules

### Recommended Ratios by Use Case
| Ratio | Name | Best For | Contrast Feel |
|-------|------|----------|---------------|
| 1.067 | Minor second | Dense data UIs, dashboards | Very subtle |
| 1.125 | Major second | Apps, SaaS products, dense UIs | Subtle |
| 1.200 | Minor third | General-purpose, balanced | **Recommended default** |
| 1.250 | Major third | Blogs, content sites | Moderate |
| 1.333 | Perfect fourth | Marketing, editorial | **Recommended for impact** |
| 1.414 | Augmented fourth | Magazines, portfolios | Dramatic |
| 1.500 | Perfect fifth | Hero-heavy landing pages | Very dramatic |
| 1.618 | Golden ratio | Special/artistic use | Extreme |

### Standard Scale (1.250 ratio — Major Third)
| Step | Size (rem) | Size (px) | Use |
|------|-----------|-----------|-----|
| xs | 0.64rem | 10.24px | Captions, legal text (use sparingly) |
| sm | 0.8rem | 12.8px | Labels, helper text, metadata |
| base | 1rem | 16px | Body text |
| md | 1.25rem | 20px | Large body, subheadings |
| lg | 1.563rem | 25px | H4, card titles |
| xl | 1.953rem | 31.25px | H3 |
| 2xl | 2.441rem | 39.06px | H2 |
| 3xl | 3.052rem | 48.83px | H1 |
| 4xl | 3.815rem | 61.04px | Display/hero text |

### Practical Scale (1.200 ratio — Minor Third)

| sm | 0.833rem | 13.3px | Labels, helper text |

| 4xl | 2.986rem | 47.8px | Display/hero |

### Font Weight Usage
| Weight | Value | Use |
|--------|-------|-----|
| Regular | 400 | Body text, most content |
| Medium | 500 | UI labels, subtle emphasis |
| Semibold | 600 | Subheadings, card titles, buttons |
| Bold | 700 | Main headings, strong emphasis |

**Rule:** Use 2–3 weights maximum per page. Weight and size together create hierarchy — you don't need both for every level.

## CSS/Implementation Patterns

### CSS Custom Properties Type Scale
```css
:root {
  /* Base */
  --font-size-base: 1rem;        /* 16px — never go below this for body */

  /* Scale (1.25 — Major Third) */
  --font-size-xs: 0.64rem;       /* 10.24px */
  --font-size-sm: 0.8rem;        /* 12.8px */
  --font-size-md: 1.25rem;       /* 20px */
  --font-size-lg: 1.563rem;      /* 25px */
  --font-size-xl: 1.953rem;      /* 31.25px */
  --font-size-2xl: 2.441rem;     /* 39.06px */
  --font-size-3xl: 3.052rem;     /* 48.83px */
  --font-size-4xl: 3.815rem;     /* 61.04px */

  /* Line heights — tighter for headings, looser for body */
  --line-height-tight: 1.2;      /* Headings */
  --line-height-normal: 1.5;     /* Body text */
  --line-height-loose: 1.75;     /* Small text, captions */

  /* Font weights */
  --font-weight-regular: 400;
  --font-weight-medium: 500;
  --font-weight-semibold: 600;
  --font-weight-bold: 700;
}
```

### Heading Styles
```css
h1 {
  font-size: var(--font-size-3xl);
  font-weight: var(--font-weight-bold);
  line-height: var(--line-height-tight);
  letter-spacing: -0.02em;       /* Tighten tracking on large text */
}

h2 {
  font-size: var(--font-size-2xl);
  font-weight: var(--font-weight-bold);
  line-height: var(--line-height-tight);
  letter-spacing: -0.01em;
}

h3 {
  font-size: var(--font-size-xl);
  font-weight: var(--font-weight-semibold);
  line-height: var(--line-height-tight);
}

h4 {
  font-size: var(--font-size-lg);
  font-weight: var(--font-weight-semibold);
  line-height: var(--line-height-tight);
}

body {
  font-size: var(--font-size-base);
  font-weight: var(--font-weight-regular);
  line-height: var(--line-height-normal);
}

small, .text-sm {
  font-size: var(--font-size-sm);
  line-height: var(--line-height-loose);
}
```

### Fluid Type Scale with clamp()
```css
/* Scale smoothly between 768px and 1280px viewport */
:root {
  --font-size-base: clamp(1rem, 0.95rem + 0.25vw, 1.125rem);
  --font-size-md: clamp(1.2rem, 1.1rem + 0.5vw, 1.5rem);
  --font-size-lg: clamp(1.44rem, 1.2rem + 1vw, 2rem);
  --font-size-xl: clamp(1.728rem, 1.3rem + 1.8vw, 2.5rem);
  --font-size-2xl: clamp(2.074rem, 1.5rem + 2.5vw, 3.5rem);
  --font-size-3xl: clamp(2.488rem, 1.5rem + 3.5vw, 4.5rem);
}
```

## Common Mistakes

1. **Body text below 16px** — 14px was acceptable in 2010. It's not accessible now. Use 16px minimum for body text.
2. **Too many sizes** — if you have 12 distinct font sizes, you don't have a system. Limit to 5–7 from your scale.
3. **Using `px` for font sizes** — users who set their browser to 20px base won't benefit from your layout. Use `rem`.
4. **Same line-height for all sizes** — headings need tighter line-height (1.1–1.3) than body text (1.4–1.6). Large text with 1.5 line-height looks airy and disconnected.
5. **Not tightening letter-spacing on large text** — display/hero text needs negative letter-spacing (-0.01 to -0.03em) to avoid looking too loose.
6. **Mixing scale ratios** — pick one ratio and stick with it. If 1.25 doesn't produce the exact value you want for h3, use the closest scale value anyway.

## Decision Tree

```
Choosing a type scale:
├─ What type of project?
│  ├─ Data-dense app/dashboard → 1.125 (major second) or 1.200 (minor third)
│  ├─ SaaS/productivity app → 1.200 (minor third) or 1.250 (major third)
│  ├─ Content/blog site → 1.250 (major third) or 1.333 (perfect fourth)
│  ├─ Marketing/landing page → 1.333 (perfect fourth) or 1.414
│  └─ Portfolio/editorial → 1.414+ (augmented fourth or higher)
├─ How many heading levels needed?
│  ├─ 2–3 levels → Higher ratio is fine (more visual contrast per step)
│  └─ 5–6 levels → Lower ratio needed (otherwise h1 is enormous)
└─ Responsive?
   ├─ Yes → Use clamp() for fluid scaling
   └─ No → Use fixed rem values with media query overrides
```

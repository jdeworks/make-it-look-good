Rule-based scoring against WCAG, Material Design, and typography best practices. Checks computed styles — no AI, just evidence and math.

How it works: The page is fetched via proxy and rendered in a sandboxed iframe. JavaScript is off by default — for JS-heavy sites (React, Vue, Angular), enable it below. Storage, cookies, and other sensitive APIs are automatically isolated. Pages behind login, localhost, or sites that block proxies/framing need the Console Snippet tab instead.

Sources
  • Contrast 4.5:1 / 7:1 — WCAG 2.2 §1.4.3 (AA) and §1.4.6 (AAA)
  • Touch target 44px — WCAG 2.2 §2.5.8; 48dp from Material Design 3
  • Click target 24px — WCAG 2.2 §2.5.8 minimum for non-inline targets
  • 16px body text — Browser default; NNGroup research on minimum legibility
  • 18px for elderly — W3C WAI Older Users and WCAG large text definition (18pt = 24px, 14pt bold = 18.5px)
  • 48px targets for motor/elderly — Material Design 3 (48dp); Apple HIG (44pt)
  • 12px target spacing — WCAG 2.2 §2.5.8 spacing exception; Motor impairment research via COGA Task Force
  • Line height 1.4–1.6 — WCAG 2.2 §1.4.12 (1.5× minimum); Butterick's Practical Typography
  • No thin fonts for elderly — W3C WAI Developing for Older Users: avoid font-weight below 400
  • CVD palette simulation — Machado et al. 2009; WCAG 2.2 §1.4.1
  • Reading level Grade 5/8 — WCAG 2.2 §3.1.5; Flesch-Kincaid / Coleman-Liau index
  • Max 5 nav items — Cowan (2001): working memory 4±1; NNGroup children UX
  • Children touch targets — NNGroup Physical Development: 48px min, 76px ideal for ages 4-8
  • Cognitive/COGA — W3C Making Content Usable: short sentences, consistent nav, icon+text

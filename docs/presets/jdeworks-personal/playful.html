The Origin Story

Picture this: a teenager who should be doing homework, instead inspecting every website's source code and thinking "I could make this better." Spoiler alert -- that teenager grew up and is still doing exactly that, just now people pay for it.

I went from hacking together MySpace layouts to building production systems that handle millions of users. The journey taught me that the best products come from people who obsess over both the code and the craft.

These days I live at the intersection of design and engineering -- where a perfect API meets a perfect interface. It's a great neighborhood.

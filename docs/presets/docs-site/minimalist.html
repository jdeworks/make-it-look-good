Installation

Get DevKit up and running in your project in under two minutes.

Prerequisites

You will need Node.js 18 or later and a package manager (npm, yarn, or pnpm) installed on your machine.

Install the package

Install DevKit using your preferred package manager:

# Using npm
npm install @devkit/core

# Using yarn
yarn add @devkit/core

# Using pnpm
pnpm add @devkit/core

The package is approximately 45KB gzipped with zero dependencies.

DevKit requires a peer dependency on react@18+ if you are using the React bindings. The core package works framework-free.

Configuration

Create a configuration file in your project root. DevKit supports both ESM and CommonJS formats:

export default {
  apiKey: process.env.DEVKIT_API_KEY,
  environment: "production",
  debug: false,
};

Supported file names: devkit.config.js, devkit.config.mjs, devkit.config.ts

Options

apiKey
Your API key from the dashboard. Required.
environment
Set to "production" or "staging". Defaults to "production".
debug
Enable verbose logging for troubleshooting.
timeout
Request timeout in milliseconds. Defaults to 5000.

Verify installation

Run the following command to confirm everything is working:

npx devkit doctor

You should see output similar to:

✓ Node.js version: 20.11.0
✓ DevKit core: 2.4.0
✓ Config file found
✓ API key valid
✓ All checks passed

Troubleshooting

Common issues and their solutions:

Node.js version mismatch

DevKit requires Node.js 18+. Check your version with node --version and upgrade if needed.

Permission errors

Avoid using sudo with npm. Configure npm to use a different directory for global installations instead.

Running sudo npm install can create ownership problems. Use nvm to manage Node.js versions instead.

Peer dependency warnings

These warnings are informational and can be safely ignored if you are not using the React bindings. Install react@18+ to resolve them.

TypeScript configuration

If you are using TypeScript, DevKit ships its own type declarations. No additional @types package is needed. Ensure your tsconfig.json includes "moduleResolution": "bundler" or "node16".

{
  "compilerOptions": {
    "moduleResolution": "bundler",
    "strict": true
  }
}

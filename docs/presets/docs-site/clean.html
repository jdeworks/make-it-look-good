Installation

Get DevKit up and running in your project in under two minutes.

Prerequisites

Before installing DevKit, make sure you have Node.js 18 or later and a package manager (npm, yarn, or pnpm) installed on your machine.

Install the package

Install DevKit using your preferred package manager:

Terminal 
# Using npm
npm install @devkit/core

# Using yarn
yarn add @devkit/core

# Using pnpm
pnpm add @devkit/core

Note

DevKit requires a peer dependency on react@18+ if you are using the React bindings. The core package works framework-free.

Configuration

Create a configuration file in your project root:

devkit.config.js 
export default {
  apiKey: process.env.DEVKIT_API_KEY,
  environment: "production",
  debug: false,
};

Configuration options

Option Description
apiKey Your API key from the dashboard. Required for all API calls.
environment Set to "production" or "staging". Defaults to "production".
debug Enable verbose logging for development troubleshooting.
timeout Request timeout in milliseconds. Defaults to 5000.

Verify installation

Run the following command to verify everything is working:

Terminal 
npx devkit doctor

# Expected output:
✓ Node.js version: 20.11.0
✓ DevKit core: 2.4.0
✓ Config file found
✓ API key valid
✓ All checks passed

Troubleshooting

If you encounter issues during installation, try these common fixes:

Node.js version mismatch

DevKit requires Node.js 18 or later. Check your version with node --version and upgrade if needed. We recommend using nvm to manage multiple Node.js versions.

Permission errors

If you see EACCES permission errors, avoid using sudo with npm. Instead, configure npm to use a different directory for global packages.

Warning

Never run sudo npm install as this can create ownership problems in your project directory.

Installation

Get DevKit up and running in your project in under two minutes.

Prerequisites

Before installing DevKit, make sure you have Node.js 18 or later and a package manager (npm, yarn, or pnpm) installed.

Install the package

Install DevKit using your preferred package manager:

Terminal 
# Using npm
npm install @devkit/core

# Using yarn
yarn add @devkit/core

# Using pnpm
pnpm add @devkit/core
💡

Good to know

DevKit requires a peer dependency on react@18+ if you are using the React bindings. The core package works framework-free.

Configuration

Create a configuration file in your project root:

devkit.config.js 
export default {
  apiKey: process.env.DEVKIT_API_KEY,
  environment: "production",
  debug: false,
};

Configuration options

Option Description
apiKey Your API key from the dashboard. Required for all API calls.
environment Set to "production" or "staging". Defaults to "production".
debug Enable verbose logging for development troubleshooting.
timeout Request timeout in milliseconds. Defaults to 5000.

Verify installation

Run the following command to verify everything is working:

Terminal 
npx devkit doctor

Troubleshooting

Running into issues? Here are some common fixes:

Node.js version mismatch

DevKit requires Node.js 18 or later. Check your version with node --version and upgrade if needed.

Permission errors

Avoid using sudo with npm. Use nvm to manage Node.js versions instead.

⚠️

Heads up

Running sudo npm install can create file ownership problems. Always install packages without elevated privileges.

Features

01

Fast Builds

Incremental compilation with dependency-aware caching. Sub-100ms rebuilds.

02

Zero Config

Sensible defaults for TypeScript, React, Vue, and Node. Override only what you need.

03

Edge Deploy

Single-command deploys to global edge. TLS provisioned automatically.

04

Monitoring

Built-in error tracking and request tracing with zero additional dependencies.

05

Auth

OAuth, JWT, and sessions. Middleware included. No third-party service required.

06

Plugins

Composable plugin API with TypeScript types. Hot-reload during development.

Simple configuration

One file. Full control. TypeScript-native with inference and validation.

  • •Type-checked config
  • •Auto-reload on save
  • •Composable stages
flux.config.ts 
import { defineConfig } from '@flux/cli'
import { typescript, node } from '@flux/presets'

export default defineConfig({
  extends: [typescript(), node()],
  build: {
    target: 'es2024',
    minify: true,
    sourcemap: true,
  },
  deploy: {
    provider: 'edge',
    regions: ['auto'],
  },
})

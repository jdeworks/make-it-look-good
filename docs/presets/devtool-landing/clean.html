Features

Everything you need to ship

Lightning Builds

Incremental compilation with smart caching. Build times under 100ms for most projects.

Zero Config

Works out of the box with TypeScript, React, Vue, Svelte, and more. No config files needed.

Edge Deploys

Deploy to 300+ edge locations worldwide with a single command. SSL and CDN included.

Real-time Metrics

Built-in monitoring dashboard with error tracking, performance metrics, and usage analytics.

Built-in Auth

Authentication and authorization with OAuth, JWT, and session management out of the box.

Plugin System

Extend with community plugins or write your own. Full TypeScript API with hot-reload support.

Usage

Configure in seconds

Define your pipeline with a simple config. TypeScript-native with full autocompletion and type safety.

  • Type-safe configuration
  • Hot-reload on config changes
  • Composable pipeline stages
acme.config.ts 
import { defineConfig } from '@acme/cli'

export default defineConfig({
  name: 'my-project',
  build: {
    target: 'es2024',
    minify: true,
    sourcemap: true,
  },
  deploy: {
    provider: 'edge',
    regions: ['us-east', 'eu-west'],
  },
})

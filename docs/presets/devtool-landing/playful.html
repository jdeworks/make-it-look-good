Usage

Config that sparks joy

One tiny config file, infinite possibilities. TypeScript-native with full autocompletion.

  • ✨ Type-safe with autocomplete
  • ⚡ Hot-reload on every save
  • ✓ Composable pipeline stages
spark.config.ts 
import { defineConfig } from '@spark/cli'
import { react, tailwind } from '@spark/plugins'

export default defineConfig({
  name: 'my-app',
  plugins: [react(), tailwind()],
  build: {
    target: 'es2024',
    minify: true,
    sourcemap: true,
  },
  deploy: {
    provider: 'edge',
    regions: ['us-east', 'eu-west', 'ap-south'],
  },
})

Button System

E-commerce component library · Pill shapes · Bouncy interactions

1. Primary Buttons

Gradient filled pills · High emphasis

When to use: The single most important action per section.

2. Secondary Buttons

Outlined pills · Medium emphasis

When to use: Supporting actions paired with primary buttons.

3. Destructive Buttons

Red pills · Irreversible actions

When to use: Permanent actions. Always confirm first.

4. Ghost Buttons

Text only with hover bg · Low emphasis

When to use: Least important actions — Cancel, Skip, Learn More.

5. Icon Buttons

Icon-only circles · Compact actions

When to use: Compact actions in toolbars and rows. Always include aria-label.

6. Button Group

Connected pills · Segmented controls

When to use: View switching, pagination, or multi-action bars.

7. Loading State

Spinner · Preserves width

Implementation: Set disabled, aria-busy, and min-width to prevent layout shift.

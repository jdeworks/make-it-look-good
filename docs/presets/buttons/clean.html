Button System

E-commerce component library · 6 variants × 4 states × 3 sizes

Primary color: emerald-800 (#065f46) · Min touch target: 44px · WCAG AA compliant

1. Primary Buttons

Filled green · High emphasis · One per visual section maximum

Small (36px visible / 44px touch target)

Medium (44px — default)

Large (52px — hero CTAs, checkout)

State labels: Default Hover Focus Disabled Loading

When to use: The primary button is for the single most important action on the screen — "Add to Cart," "Place Order," "Sign Up." Limit to one primary button per visual section.

2. Secondary Buttons

Outlined · Medium emphasis · Supporting actions

Small

Medium

Large

When to use: Secondary buttons pair with primary buttons as the less-important option. "Continue Shopping" next to "Checkout," or "Save for Later" next to "Add to Cart."

3. Destructive Buttons

Red filled · Irreversible or dangerous actions

Small

Medium

Large

When to use: Destructive buttons are for permanent or hard-to-undo actions — "Delete Account," "Remove Item," "Cancel Subscription." Always pair with a confirmation step.

4. Ghost Buttons

No border, text + hover background · Low emphasis · Tertiary actions

Small

Medium

Large

When to use: Ghost buttons are for the least important actions — "Cancel," "Skip," "Learn More." They reduce visual clutter when many actions are present, like in toolbars or table rows.

6. Button Group

Connected buttons · Segmented controls and multi-action bars

Segmented Control

Action Bar

When to use: Button groups work for related actions like view switching (List/Grid/Board), pagination, or multi-action bars on selected items.

7. Loading State

Button with spinner · Shows processing state while preserving width

Implementation notes: Always set disabled, aria-busy="true", and min-width to prevent layout shift. Show label text alongside the spinner when space permits.

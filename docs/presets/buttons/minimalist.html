Button System

E-commerce component library · Ghost/outline only · Minimal visual weight

1. Primary Buttons

Outlined · High emphasis · One per section

When to use: Single most important action per section.

2. Secondary Buttons

Outlined thin · Medium emphasis

When to use: Supporting actions paired with primary buttons.

3. Destructive Buttons

Red outline · Irreversible actions

When to use: Permanent or hard-to-undo actions. Always confirm first.

4. Ghost Buttons

Text only · Low emphasis · Tertiary actions

When to use: Least important actions — Cancel, Skip, Learn More.

5. Icon Buttons

Icon-only · Minimal chrome

When to use: Compact actions in toolbars and table rows. Always include aria-label.

6. Button Group

Connected buttons · Segmented controls

When to use: Related actions like view switching or multi-action bars.

7. Loading State

Spinner · Preserves width

Implementation: Set disabled, aria-busy, and min-width to prevent layout shift.

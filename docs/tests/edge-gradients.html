Gradient Contrast Edge Cases

Test 1: Multiple linear-gradient layers (white 85% overlay)

Easily create accurate translations for your content in minutes.

Expected: PASS (black on near-white ~18:1). Bug previously reported this as 1.66:1
Test 2: Radial gradient dot pattern

This text sits on a subtle radial dot pattern with a beige background color.

Expected: PASS (dark text on beige ~15:1). Radial dots are tiny and shouldn't affect reading
Test 3: Dark diagonal gradient

Light text on a dark diagonal gradient background.

Expected: PASS (light on dark ~11:1)
Test 4: Low contrast gradient (should fail)

Gray text on a light gray gradient — this should be flagged.

Expected: FAIL (gray on gray ~1.5-2:1)
Test 5: Semi-transparent overlay on white

Nearly black text on a barely tinted white surface.

Expected: PASS (near-black on near-white ~19:1)
Test 6: Triple-layer gradient stack

Dark text on three stacked gradient layers that composite to near-white.

Expected: PASS (dark on composited near-white ~18:1)
Test 7: oklch gradient colors

Dark text on a subtle oklch gradient background.

Expected: PASS (dark on light ~11:1). Tests modern color format support.
Test 8: Barely passing contrast

Medium gray text on a very light gradient.

Expected: INFO (barely passes ~4.5-5:1). Should NOT be error or warning.
Test 9: Gradient that hides text (should fail)

Red text on a red-orange gradient — nearly invisible.

Expected: FAIL (red on red ~1.2:1)
Test 10: Conic gradient (fallback)

Text on a conic gradient — parser may not support this yet.

Expected: Either PASS or UNCERTAIN (conic not parsed → white fallback → passes)
